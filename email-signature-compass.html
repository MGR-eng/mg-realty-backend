How to install in Gmail (Compass account)

  1. Open this file in your browser (double-click it)
  2. Select everything below the dashed line
  3. Copy (Cmd+C)
  4. Open your Compass Gmail → Settings (gear) → See all settings → General
  5. Scroll to Signature → create or edit → paste (Cmd+V)
  6. Scroll down → Save Changes
