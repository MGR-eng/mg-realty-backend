How to install in Gmail

  1. Open this file in your browser (double-click it)
  2. Select everything below the dashed line (from the black accent bar to the bottom of the DRE number)
  3. Copy (Cmd+C)
  4. Open Gmail → Settings (gear) → See all settings → General
  5. Scroll to Signature → create or edit → paste (Cmd+V)
  6. Scroll down → Save Changes

⚠️ The animated GIF uses a relative path (logo-cycle.gif). For Gmail, you'll need to host the GIF publicly (e.g. upload it to Google Drive and get a share link, or Imgur) and update the src in the HTML before pasting. Replace [YOUR_HEADSHOT_URL] with your headshot URL too.
